# 🎮 Classroom Games — 3rd Grade

Quick 1–2 minute skill games for 3rd graders, styled like ClassCade. **Each game is completely standalone with its own link** — there is no shared menu, so you can hand out exactly the game you want students to play. Every game is a single HTML file that works on computers and tablets; best scores save on the device.

## How every game plays

Every game fills the **whole screen**, uses no timer, and has **no lives to count**. Instead, wrong answers build a themed danger meter (fire, lava, ghosts, zombies, a rising river…) and a correct answer cools it back down. Push the meter too far and the round ends — then the game **restarts itself instantly**, no click needed, so kids stay in the flow. There are no mini-lessons popping up and no star rating — just quick action, coins, and a 3-in-a-row streak that doubles your coins.

Each game is its own little world with its own character and arcade mechanic, inspired by classic games:

- 🍝 **Meatball Launch!** (*Angry Birds*) — sling Chef Meatball into the **Persuade / Inform / Entertain** pot.
- 🎤 **Who Should Say It?** (*talent show*) — tap the word-star who'd say each line (simile, metaphor, alliteration…).
- ⛓️ **Build the Chain** (*treasure haul*) — forge chain links by picking the best prediction or reader question.
- 🌋 **Beat the Lava!** (*survival climb*) — climb with Kiko the gecko as the lava rises; sort syllable types.
- 🩺 **Evidence Operation!** (*Operation*) — tweeze out the line that PROVES it, what came first, or the best retell.
- 🔍 **Evidence Tap** (*detective board*) — pin the clue that answers the case (synthesize, support, key idea).
- 🧑‍🌾 **Story Farm** (*Stardew farm*) — grow crops by answering *what happened*, *mostly about*, and *word meaning*.
- 🍄 **Tense Jump!** (*Mario platform*) — jump to the Past / Present / Future block to reach the castle.
- 🎣 **Fish for Words** (*fishing*) — reel in the synonym, antonym, homophone, or idiom (a wrong catch is a stinky boot!).
- 🏃 **ABC Sprint!** (*Sort Sprint*) — tap the word that comes first (or last) in ABC order and race the track.
- 🏎️ **Grammar Grand Prix** (*kart racing*) — overtake by naming the adjective, adverb, or preposition.
- 🥔 **Spud Swap!** (*Mr. Potato Head*) — snap on the right part: replace a noun with a pronoun, or spot the noun.
- 🕹️ **Word Claw!** (*The Claw*) — grab the piece that makes a compound word, contraction, or abbreviation.
- 🔺 **Dash Gate!** (*Geometry Dash*) — pick the gate for simple vs. compound sentences and the joining word.
- 🚀 **Syllable Blaster!** (*Galaga*) — blast the right number of syllables, or where a word splits.
- 🌱 **Affix Garden** (*Plants vs Zombies*) — plant the right prefix, suffix, or spelling to hold back the zombies.
- 🐸 **Word Hopper!** (*Frogger*) — hop to the lily pad with the high-frequency word that fills the blank.
- 🟡 **Theme Muncher** (*Pac-Man*) — chomp the lesson (theme) of each short story.
- 🎂 **Story Cake!** (*decorating cakes*) — add a layer by naming the setting, character, or plot part.
- 🔎 **Trap or Fact** (*catch the clue*) — use context clues to catch a word's real meaning and dodge the trap.
- 🫧 **Rhyme Pop!** (*match bubbles*) — pop the rhyme, or the poetry trick (repetition, sound words, comparisons).
- 📖 **Story Trail** (*storybook walk*) — collect books by knowing fables, fairy tales, folktales, and story parts.

## The links stay live automatically

Publishing is handled by a GitHub Actions workflow (`.github/workflows/pages.yml`) using GitHub's official Pages deployment. It turns Pages on by itself and republishes on every change, so every link in the table above stays up to date — no manual Settings step needed.

If you ever need to check it, the deployment status lives at **https://github.com/pastorsophia/ck12-games/actions** and the Pages settings at **https://github.com/pastorsophia/ck12-games/settings/pages** (Source should read **GitHub Actions**).

## Offline use

Any game also works with no internet: download its `index.html`, then double-click it. (Online, games load the Poppins font from Google Fonts; offline they fall back to a similar built-in font.)

## Adding more games

Each topic gets its own folder with an `index.html` — one folder = one shareable link.
